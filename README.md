# Odin Book

## Goal

Build a Threads-style social site where signed-in users can share posts and interact with people they follow.

## Core experience

- Visitors see a sign-in page.
- People can create an account and sign in with a username and password.
- Signed-in users can find other users and send follow requests.
- Users can accept or decline follow requests.
- Users can write text posts, like posts, and comment on posts.
- The home feed shows recent posts from the signed-in user and people they follow.
- Each user has a profile page with their information, profile picture, and posts.
- Each post shows its content, author, comments, and likes.
- The finished app will be deployed online.

## Extra credit

- Allow an image URL on a post.
- Let users change their profile picture.
- Provide guest sign-in so visitors can explore without creating an account.
- Improve the site's visual design.

## Outside this project's scope

- Private messages
- Real-time notifications
- Live chat
